# Task Management API

Basit bir task yönetim API’si geliştirdim. 
Backend tarafında Express.js kullandım ve JWT ile authentication yapısını kurdum.

## Yapılacaklar

- JWT authentication
- Task CRUD işlemleri
- Swagger dokümantasyonu

## Endpointler

- POST /task
- GET /tasks
- GET /tasks/:id
- PUT /tasks/:id
- DELETE /tasks/:id

## Proje Kurulumu && Test

npm install
npm start
